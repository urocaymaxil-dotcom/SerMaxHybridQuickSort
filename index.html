Bidirectional Partitioning

Initialize boundaries and opposing pointers (i, j), scan from two directions around v = A[p_abs], compare, swap, and advance pointers, handle repeated values and edge cases, and generate left/right subproblems.

1v = A[p_abs]; i = low; j = high; // Save pivot value v before swaps
2while (i <= j && A[i] < v) { i++; } // Left scan stops on A[i] >= v
3while (i <= j && A[j] > v) { j--; } // Right scan stops on A[j] <= v
4if (i <= j) { if (i < j) swap(A, i, j); // Physical swap only when i < j
5 i++; j--; } // Advance both pointers (prevents infinite loop on duplicates)
6return Left [low..j] (n_L = max(0, j-low+1)), Right [i..high] (n_R = max(0, high-i+1));
